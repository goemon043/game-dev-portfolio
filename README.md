## 📖 Sobre Mí

¡Bienvenido a mi portafolio de desarrollo de videojuegos! Soy un estudiante apasionado por la creación de experiencias interactivas que combinen diversión, aprendizaje y creatividad. Me especializo en el desarrollo de juegos educativos y narrativos utilizando tecnologías web (HTML5, CSS3, JavaScript).

**Mis intereses:**
- 🎓 **Educación mediante juegos**: Crear experiencias que enseñen mientras divierten
- 📱 **Tecnologías web**: Desarrollo accesible sin necesidad de instalaciones
- 🎨 **Diseño creativo**: Interfaces atractivas y mecánicas innovadoras
- 🧠 **Aprendizaje continuo**: Cada proyecto es una oportunidad para mejorar
